# 🇫🇷 France Crisis Intelligence

An evidence-first data science project for monitoring France's economic and social indicators.

## Objectives

- Monitor inflation and food-price changes.
- Study employment and purchasing power.
- Track euro exchange rates using verified sources.
- Explore historical trends and baseline forecasts.
- Present findings through an interactive dashboard.

## Technology Stack

- Python
- Pandas and NumPy
- Plotly
- Streamlit
- Scikit-learn

## Run Locally

Install the dependencies:

```bash
pip install -r requirements.txt
```

Launch the dashboard:

```bash
streamlit run app.py
```

## Data Integrity

**Current status:** The dashboard uses illustrative demo data.

It does not yet provide verified live statistics or establish that France is experiencing a crisis. Official data must be connected and validated before drawing conclusions.
